Coreference Resolution (대응 표현 해소)

난이도 / Difficulty: Intermediate
날짜 / Date: 2026-07-27

내용

코어퍼런스 해소는 텍스트에서 서로 같은 실체를 가리키는 표현들(예: "그", "Alice", "그녀의")을 연결하는 기술로, 검색·요약·대화 시스템의 의미 일관성에 필수적입니다.

작동 원리: 전통적 방법은 명사구 탐지 + 규칙 기반 특징(성, 수, 거리) 매칭이었지만, 실제 대규모 시스템에서는 신경망 기반 스팬-투-스팬(score) 모델이 주류입니다. 대표적 접근은 Lee et al. (2017) 의 end-to-end 모델로, 모든 가능한 스팬(명사구 후보)을 임베딩하고 쌍별 점수와 멘션 허용 확률을 결합해 클러스터를 구성합니다. 후속 연구(SpanBERT 등)는 스팬 표현 품질을 높이고 앙상블/리랭킹을 도입해 실전 성능을 개선했습니다.

운영 관점: 배치 파이프라인에서는 토큰화→NER/사전처리→코어퍼런스 모델→후처리(굴절/정규화)로 이어집니다. 대화 시스템은 실시간 제약 때문에 스트리밍(최근 발화만 유지) 또는 분해능(confine) 전략을 씁니다. 성능 지표는 MUC, B^3, CEAF 등이며, 불확실성(모델 점수)을 상용 규칙(예: 고신뢰도 일치만 병합)으로 조절해 오탐을 줄입니다.

활용

실제 사용 사례 및 코드
- AllenNLP (Lee et al. 기반): 모델 다운로드/예측
from allennlp.predictors.predictor import Predictor\n predictor = Predictor.from_path('https://storage.googleapis.com/allennlp-public-models/coref-model-2018.03.14.tar.gz')\n out = predictor.predict(document='Alice went to the store. She bought milk.')\n # out['clusters'] => [[ [0,0], [3,3] ]]
(사용처: 연구/프로토타입, 법률문서 색인화, 문서 요약 전처리)

- spaCy + coreferee (생산성 높은 파이프라인):\n import spacy\n import coreferee\n nlp = spacy.load('en_core_web_trf')\n nlp.add_pipe('coreferee')\n doc = nlp('Angela called Bob. He answered.')\n print(doc._.coref_chains)
(사용처: 챗봇 컨텍스트 관리, 고객지원 로그 연계)

참고 논문/모델: Lee et al., 2017 (end-to-end), Joshi et al., 2020 (SpanBERT). 실무 베스트프랙티스: 고신뢰도 병합 규칙, 스트리밍 제약, 도메인별 사전 학습(legal/medical)과 오류 분석 중심의 데이터 보강.

Content

Coreference resolution links mentions that refer to the same entity (e.g., "Alice", "she", "the user") and is critical for search, QA, summarization, and dialogue coherence in production systems.

How it works: Early systems used mention detection plus rule/feature-based pairwise classifiers (gender/number/recency). Modern production and research favor span-based neural models (Lee et al., 2017) that enumerate candidate spans, compute span embeddings (context-aware), score mentionness, and score antecedent links to form clusters. Improvements (SpanBERT, better contextual encoders) reduce ambiguity and increase cross-sentence linking.

Operationally, coreference is a pipeline stage: tokenization → mention detection → coref model → cluster post-processing. For online systems (chatbots, assistants) latency and memory force streaming or windowed strategies (keep only recent utterances), and applications often apply precision thresholds to avoid false merges. Evaluation uses MUC, B^3, and CEAF metrics; production tuning emphasizes precision over recall where mistakes are costly.

Applications

Real-world tools and code
- AllenNLP (Lee et al. implementation):
from allennlp.predictors.predictor import Predictor
predictor = Predictor.from_path('https://storage.googleapis.com/allennlp-public-models/coref-model-2018.03.14.tar.gz')
out = predictor.predict(document='Alice went to the store. She bought milk.')
# out['clusters'] => [[ [0,0], [3,3] ]]
(Used for document understanding, e-discovery preprocessing, summarization pipelines)

- spaCy + coreferee (spaCy v3 transformer pipeline):
import spacy
import coreferee
nlp = spacy.load('en_core_web_trf')
nlp.add_pipe('coreferee')
doc = nlp('Angela called Bob. He answered.')
print(doc._.coref_chains)
(Used in chat systems for context tracking and customer support automation)

References: Lee et al., 2017 (end-to-end neural coref), Joshi et al., 2020 (SpanBERT). Production best practices: thresholding for precision, domain-specific fine-tuning, streaming/windowing for latency, and human-in-the-loop correction on high-impact flows.
