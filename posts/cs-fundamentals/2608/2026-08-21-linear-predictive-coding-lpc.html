Linear Predictive Coding (LPC)

난이도 / Difficulty: Intermediate
날짜 / Date: 2026-08-21

내용

LPC(선형 예측 부호화)는 현재 음성 샘플을 과거 샘플의 선형 조합으로 모델링해 저비트레이트 전송과 음성 합성에서 핵심 역할을 합니다. 실무에서는 코덱, 음성 합성의 프레임별 피처, 그리고 하이브리드 신경 vocoder에 널리 쓰입니다.

원리: 프레임 단위로 신호를 윈도잉한 뒤 자가상관을 계산하고 Levinson–Durbin 알고리즘으로 예측계수(a1..ap)를 구합니다. 신호는 x[n] ≈ Σ_{i=1..p} a_i x[n-i]로 근사되며, 잔차(Excitation)=x[n]-prediction을 전송하거나 합성에 사용합니다. 실무 파라미터: 전화(8 kHz)에선 p≈8~12, 와이드밴드(16 kHz)엔 p≈16~20이 일반적입니다.
실제 시스템: CELP 계열(예: G.729), Speex, Skype의 SILK 파트(후에 Opus와 통합)에서 LPC 기반 예측/필터링을 사용합니다. 최근 연구인 LPCNet(Valin & Skoglund, 2019)은 신경망의 입력으로 LPC 잔차를 사용해 효율적 실시간 합성을 달성했습니다. 안정성: 대역폭 확장(bandwidth expansion), 전치(pre-emphasis) 0.97 적용, Levinson–Durbin 수치 안정화가 중요합니다.

활용

간단한 파이썬 구현 예(프레임별 LPC+잔차):
import numpy as np
from scipy.signal import lfilter

def levinson(r,order):
a=np.zeros(order+1); a[0]=1.0; e=r[0]
for i in range(1,order+1):
acc=sum(a[j]*r[i-j] for j in range(0,i))
k=-(r[i]+acc)/e
a[1:i]=[a[j]+k*a[i-j] for j in range(1,i)]
a[i]=k; e*=1-k*k
return a

# y: frame signal, order=16
r=np.correlate(y, y, 'full')[len(y)-1:]
A=levinson(r,16)
residual=lfilter(A,1,y)

현업 팁: pre-emphasis, 창 크기(20~30ms), 오더를 샘플링율에 맞춰 조정, 코덱에서는 계수 양자화+안정화 필요. 참고: Opus (RFC 6716), Speex, ITU-T G.729, LPCNet 논문.

Content

Linear Predictive Coding models each speech sample as a linear combination of past samples; it’s fundamental for low-bitrate codecs, feature extraction, and hybrid neural vocoders in production systems.

Core mechanics: split the signal into short frames, apply pre-emphasis and windowing, compute autocorrelation, then solve for predictor coefficients via Levinson–Durbin. The signal is approximated as x[n] ≈ Σ_{i=1..p} a_i x[n-i]; the residual (excitation) is x[n] minus the prediction. Typical orders: p≈8–12 for narrowband (8 kHz), p≈16–20 for wideband (16 kHz+). In real systems engineers apply bandwidth expansion or coefficient stabilization and quantize coefficients for transmission.
Where used: many production codecs and standards rely on LPC or LPC-based modules — CELP/G.729 in telephony, Speex (Xiph), the SILK mode in Skype (later part of Opus), and modern research like LPCNet (Valin & Skoglund, 2019) combine LPC with small neural networks for efficient synthesis.

Applications

Minimal Python example (frame LPC -> residual):
import numpy as np
from scipy.signal import lfilter

def levinson(r, order):
a = np.zeros(order+1); a[0]=1.0; e=r[0]
for i in range(1, order+1):
acc = sum(a[j]*r[i-j] for j in range(0,i))
k = -(r[i]+acc)/e
a[1:i] = [a[j] + k*a[i-j] for j in range(1,i)]
a[i] = k; e *= 1 - k*k
return a

# y = frame samples
r = np.correlate(y, y, 'full')[len(y)-1:]
A = levinson(r, 16) # predictor polynomial with A[0]=1
residual = lfilter(A, 1.0, y)

Practical tips: use pre-emphasis (~0.97), 20–30 ms frames, choose order by sampling rate, stabilize coefficients before quantization. References: Opus (RFC 6716) uses SILK (LPC-based), Speex/G.729, and the LPCNet paper for neural vocoder hybrids.
