Dropout & Regularization in Neural Networks

난이도 / Difficulty: Intermediate
날짜 / Date: 2026-09-07

내용

드롭아웃과 정규화는 과적합을 줄이고 모델 일반화 성능을 향상시키는 핵심 기법으로, 대규모 서비스와 연구에서 널리 사용됩니다.

드롭아웃(dropout)은 신경망 학습 중 무작위로 뉴런을 비활성화하여 앙상블 효과를 내는 방법입니다. L2(weight decay), 조기 중단(early stopping), 배치 정규화(batch norm)와 함께 사용되며, 트랜스포머(예: BERT)는 내부적으로 드롭아웃을 핵심 하이퍼파라미터로 사용합니다(Devlin et al., 2018). 드롭아웃은 작은 데이터셋에서 과적합 완화에 특히 유용하지만 배치 정규화와 함께 쓸 때는 효과/순서에 주의해야 합니다.

기술적으로 학습 중 각 레이어의 활성화 a_i에 대해 p 확률로 0을 곱하고, 학습/추론 시 스케일링을 조정합니다(inverted dropout). L2 정규화는 손실에 λ||w||^2 항을 추가하여 가중치 크기를 제한합니다. 현대 트랜스포머·비전 모델에서는 AdamW(가중치 감쇠 분리)를 사용해 L2 성격의 규제와 모멘텀 기반 옵티마이저를 분리합니다(Loshchilov & Hutter). 불확실성 추정을 위해 Gal & Ghahramani의 Monte Carlo dropout을 추론 시에도 활성화하여 T번 샘플링해 예측분포를 얻습니다.

활용

실무 코드 예시(핵심 패턴):
- Keras (TF):
model = tf.keras.Sequential([
tf.keras.layers.Dense(512, activation='relu', kernel_regularizer=tf.keras.regularizers.l2(1e-4)),
tf.keras.layers.Dropout(0.5),
tf.keras.layers.Dense(num_classes, activation='softmax')
])
model.compile(optimizer='adam', loss='categorical_crossentropy')
# 사용처: Keras 기반 서비스, 연구 프로토타입

- PyTorch + AdamW (권장, Hugging Face/Transformers와 동일 패턴):
import torch.nn as nn
import torch.optim as optim
model = nn.Sequential(nn.Linear(768, 768), nn.ReLU(), nn.Dropout(0.1), nn.Linear(768, num_classes))
optimizer = optim.AdamW(model.parameters(), lr=3e-5, weight_decay=0.01)

- Monte Carlo Dropout(추론 불확실성):
model.train() # dropout 활성화
preds = torch.stack([model(x) for _ in range(50)])
mean, std = preds.mean(0), preds.std(0)

실제 사용 사례: BERT/GPT 계열은 dropout≈0.1 사용(Hugging Face Transformers), Gal & Ghahramani의 MC dropout은 의료영상·자율주행 불확실성 연구에서 사용됨. Best practice: conv 계열은 배치 정규화가 있으면 드롭아웃 비율을 낮게(혹은 사용하지 않음), weight decay는 bias/LayerNorm 제외, AdamW 사용.

Content

Dropout and regularization reduce overfitting and improve generalization; they are standard tools in production models and academic work (e.g., BERT, vision models).

Dropout randomly zeros activations during training to approximate an ensemble of sub-networks, improving robustness. L2 regularization (weight decay) penalizes large weights; early stopping and data augmentation complement these techniques. In modern architectures, dropout is commonly used in transformers (Devlin et al., 2018) and vision models, but its placement and rate matter—convolutional blocks with batch norm often need little or no dropout.

Mechanically, inverted dropout scales activations during training so inference needs no post-scaling. Weight decay adds λ||w||^2 to the loss; with adaptive optimizers use AdamW to decouple weight decay from gradient updates (Loshchilov & Hutter). For predictive uncertainty, Monte Carlo (MC) dropout keeps dropout on at inference and averages T stochastic forward passes (Gal & Ghahramani, 2016). Interaction effects: dropout + batch norm can reduce effectiveness—tune order and rates accordingly.

Applications

Practical snippets used in production/research:
- TensorFlow/Keras:
model = tf.keras.Sequential([
tf.keras.layers.Dense(512, activation='relu', kernel_regularizer=tf.keras.regularizers.l2(1e-4)),
tf.keras.layers.Dropout(0.5),
tf.keras.layers.Dense(num_classes, activation='softmax')
])
model.compile(optimizer='adam', loss='sparse_categorical_crossentropy')
# Used in prototypes and services built on TF/Keras

- PyTorch + AdamW (common in Hugging Face/production):
import torch.nn as nn
import torch.optim as optim
model = nn.Sequential(nn.Linear(768, 768), nn.ReLU(), nn.Dropout(0.1), nn.Linear(768, num_classes))
optimizer = optim.AdamW(model.parameters(), lr=3e-5, weight_decay=0.01)

- MC Dropout for uncertainty:
model.train() # enable dropout
preds = torch.stack([model(x) for _ in range(50)])
mean, std = preds.mean(0), preds.std(0)

Real deployments: BERT/GPT variants use dropout≈0.1 (Devlin et al.; Hugging Face Transformers); AdamW is standard for transformer fine-tuning; MC Dropout is used in medical imaging and autonomous driving research for uncertainty estimation. Best practices: start with dropout 0.1–0.5 (lower for conv+BN), apply weight decay only to weights (not biases/LayerNorm), use AdamW for decoupled weight decay.
