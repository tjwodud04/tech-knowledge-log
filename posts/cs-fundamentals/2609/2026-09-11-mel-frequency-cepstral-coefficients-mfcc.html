Mel-Frequency Cepstral Coefficients (MFCC)

난이도 / Difficulty: Intermediate
날짜 / Date: 2026-09-11

내용

MFCC는 인간 청각의 주파수 해상도를 모사한 멜 스케일 기반의 스펙트럼 특징으로, 음성인식·스피커인식·웨이크워드 등 실무 시스템에서 널리 사용됩니다.

작동 원리: MFCC는 짧은 프레임(보통 20–30 ms)으로 신호를 분할한 뒤 창(window) 적용, FFT로 파워 스펙트럼 계산, 멜 필터뱅크로 주파수 축을 재표현한 뒤 로그를 취하고 DCT를 적용해 저차원 계수를 얻습니다. 보통 12–13개의 계수(또는 20–40)와 에너지, Δ/ΔΔ(속도·가속도)를 함께 사용합니다. 후처리로서는 pre-emphasis, liftering, 프레임 정규화(CMVN)와 길이 일관성을 위한 패딩 또는 프레임 묶음이 필요합니다.

실무 고려사항: 표준 설정은 16 kHz 샘플링, 25 ms 프레임, 10 ms 홉, 40 멜 밴드, 13 MFCC. Kaldi 같은 ASR 툴킷과 TensorFlow의 Speech Commands 튜토리얼, 모바일 웨이크워드 파이프라인 등에서 이 조합이 기본입니다. 잡음에 민감하므로 데이터 증강(잡음 추가, 시간/주파수 마스킹), CMVN과 델타 계수 사용이 권장됩니다. 최근 연구와 제품에서는 학습 가능한 프론트엔드(log-mel 또는 learnable mel-filterbanks)를 MFCC 대신 사용하기도 합니다.

활용

실무 예제(코드·명령):

1) Python + librosa (빠른 프로토타입):
import librosa
y, sr = librosa.load('audio.wav', sr=16000)
mfcc = librosa.feature.mfcc(y=y, sr=sr, n_mfcc=13, n_mels=40, hop_length=int(0.01*sr), n_fft=int(0.025*sr))
# add deltas, CMVN 등

2) PyTorch / torchaudio:
import torchaudio
waveform, sr = torchaudio.load('audio.wav')
mfcc_transform = torchaudio.transforms.MFCC(sample_rate=16000, n_mfcc=13, melkwargs={'n_mels':40,'n_fft':400,'hop_length':160})
mfcc = mfcc_transform(waveform)

3) Kaldi (배치 생산 파이프라인):
# 일반적인 스크립트 호출
steps/make_mfcc.sh --nj 20 --cmd run.pl data/train exp/make_mfcc mfcc
# 이후 feat_type=mfcc, apply-cmvn-fast, add-deltas 사용

참고: TensorFlow Speech Commands 튜토리얼은 tf.signal.mfccs_from_log_mel_spectrograms를 사용하여 모바일 웨이크워드/명령어 인식 파이프라인을 구성합니다. 실무 패턴: 표본율 고정, CMVN, 델타/델타델타 추가, 잡음/시간·주파수 변형을 통한 강건화, 특성 저장(ark/wav.scp/TFRecord)으로 I/O 최적화.

Content

MFCCs are compact spectral features based on the mel scale that approximate human auditory perception; they are a staple in production speech systems like ASR, speaker ID, and keyword spotting.

How it works: MFCC extraction frames audio (typically 20–30 ms frames with 10 ms hop), applies a window, computes the FFT magnitude/power, maps frequencies to the mel scale via a filterbank, takes the log, and applies a DCT to produce low-dimensional cepstral coefficients. Typical configs: 16 kHz sampling, 25 ms frame, 10 ms hop, 40 mel filters, 13 MFCCs + energy. Common augmentations are pre-emphasis, liftering, CMVN, and appending Δ/ΔΔ features for dynamics.

Practical notes: Kaldi, many research pipelines, and tutorials (e.g., TensorFlow Speech Commands) use MFCCs as input. MFCCs are computationally cheap and work well for classical models and constrained devices (wake-word on embedded hardware). They are, however, sensitive to noise; modern systems often combine MFCCs with augmentation (noise, SpecAugment) or replace them with learned front-ends or log-mel spectrograms for end-to-end DNNs.

Applications

Real-world examples and code:

1) librosa (fast prototyping):
import librosa
y, sr = librosa.load('audio.wav', sr=16000)
mfcc = librosa.feature.mfcc(y=y, sr=sr, n_mfcc=13, n_mels=40, n_fft=int(0.025*sr), hop_length=int(0.01*sr))
# then compute deltas and CMVN

2) torchaudio (PyTorch pipelines):
import torchaudio
waveform, sr = torchaudio.load('audio.wav')
mfcc_transform = torchaudio.transforms.MFCC(sample_rate=16000, n_mfcc=13, melkwargs={'n_mels':40,'n_fft':400,'hop_length':160})
mfcc = mfcc_transform(waveform)

3) Kaldi (production ASR feature stage):
# typical script for large-scale extraction
steps/make_mfcc.sh --nj 20 --cmd run.pl data/train exp/make_mfcc mfcc
# follow with compute-cmvn-stats and apply-cmvn-fast, add-deltas

Citations & production notes: Kaldi is a de-facto open-source ASR stack using MFCCs; TensorFlow Speech Commands tutorial shows MFCC usage for keyword spotting (https://www.tensorflow.org/tutorials/audio). Best practices: fix sampling rate, apply CMVN, add Δ/ΔΔ, use augmentation for noise robustness, and store features in efficient shards (ark/TFRecord) for training/serving.
