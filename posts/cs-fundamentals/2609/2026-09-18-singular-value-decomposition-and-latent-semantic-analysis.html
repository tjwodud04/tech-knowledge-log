Singular Value Decomposition (SVD) & Latent Semantic Analysis (LSA)

난이도 / Difficulty: Intermediate
날짜 / Date: 2026-09-18

내용

SVD는 행렬을 직교 성분과 특이값으로 분해해 저차원으로 잡음 제거·압축하고, LSA는 텍스트의 의미적 패턴을 이 저차원 표현에서 추출해 검색·추천에 활용합니다.

작동 원리: 행렬 A를 U Σ V^T로 분해하면 Σ의 큰 값들만 남겨 근사 A_k = U_k Σ_k V_k^T를 얻습니다. 문서-단어 행렬에 적용하면 동시 출현 패턴의 잠재적 주제가 추출되며 단어·문서 간 코사인 유사도 계산이 개선됩니다. 대형 희소행렬에는 Truncated/Randomized SVD(예: Halko et al.)나 ARPACK(scipy.sparse.linalg.svds)을 사용해 계산 비용·메모리를 줄입니다.
실무 포인트: 정규화(tf-idf), 희소 입력 유지, 잡음 특이값 절단, 정기적 재학습(로그적 변화 시) 등이 중요합니다. LSA는 단순하고 해석 가능해 검색 초기 랭킹, 오프라인 주제 탐지, cold-start 추천에 유용하지만, 문맥적 의미(순서·다중의미)는 단독으로 한계가 있습니다.

활용

실제 사용 예
- Gensim LSI: 소규모 토픽 모델링/검색(https://radimrehurek.com/gensim/). 코드:
from gensim import corpora, models
texts = [['apple','fruit'], ...]
d = corpora.Dictionary(texts)
corpus = [d.doc2bow(t) for t in texts]
lsi = models.LsiModel(corpus, id2word=d, num_topics=100)
- Scikit-learn TruncatedSVD: 대규모 TF-IDF에 빠른 차원축소
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.decomposition import TruncatedSVD
X = TfidfVectorizer(...).fit_transform(docs)
svd = TruncatedSVD(n_components=200).fit(X)
- Spark MLlib RowMatrix.computeSVD: 분산 환경에서 대용량 문서 행렬 분해(프로덕션 로그 분석). 권장: 입력 정규화, k 선택 실험, randomized 알고리즘 사용(Halko)으로 비용 절감.
참고: Deerwester et al. 1990(LSA), Netflix matrix factorization 사례(추천 시스템에서 SVD 기반 기법 활용).

Content

SVD decomposes a matrix into orthogonal factors and singular values for denoising and compression; LSA applies truncated SVD to term-document matrices to surface latent semantic structure for search and recommendation.

How it works: A = U Σ V^T; keeping the top-k singular values produces A_k = U_k Σ_k V_k^T, a rank-k approximation capturing dominant patterns. On a term-document tf-idf matrix, top components represent latent topics; projecting documents and queries into that low-dimensional space improves semantic similarity over raw bag-of-words. For large sparse matrices use truncated or randomized SVD (Halko et al.) or iterative solvers (ARPACK) to reduce memory and CPU.
Practical notes: pre-process with tf-idf or BM25-style weighting, preserve sparsity until decomposition, choose k by explained energy or downstream validation, and periodically recompute factors for streaming content. LSA is simple and interpretable but doesn't model word order or polysemy as well as modern contextual embeddings.

Applications

Real-world snippets & systems
- scikit-learn TruncatedSVD (fast, single-node):
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.decomposition import TruncatedSVD
X = TfidfVectorizer(...).fit_transform(docs)
svd = TruncatedSVD(n_components=200, random_state=0).fit(X)
Z = svd.transform(X)
- gensim LsiModel (topic/search):
from gensim import corpora, models
corpus = [d.doc2bow(t) for t in tokenized_docs]
dict = corpora.Dictionary(tokenized_docs)
lsi = models.LsiModel(corpus, id2word=dict, num_topics=100)
- Spark MLlib for production-scale SVD: RowMatrix.computeSVD for distributed factorization used in log analytics and recommender pipelines.
References: Deerwester et al. 1990 (LSA), Halko et al. 2011 (randomized SVD), Netflix matrix-factorization work (recommender systems). Best practice: tf-idf, sparse ops, randomized/truncated solvers, validate k by downstream metrics.
