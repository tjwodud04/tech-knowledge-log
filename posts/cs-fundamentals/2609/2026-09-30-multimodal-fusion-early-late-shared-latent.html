Multimodal Fusion: Early vs Late Fusion and Shared-Latent Representations

난이도 / Difficulty: Intermediate
날짜 / Date: 2026-09-30

내용

멀티모달 퓨전은 서로 다른 센서·모달리티(예: 이미지, 라이다, 텍스트)를 결합해 더 강건한 예측을 만드는 방법입니다. 실무에서는 지연·초기 결합 전략과 공유 잠재공간 접근이 시스템 성능·지연·확장성에 직접적인 영향을 줍니다.

초기(early) 퓨전은 서로 다른 모달리티의 표현을 낮은 수준에서 합쳐 단일 네트워크로 학습합니다. 예: 자율주행 연구에서 2D 세그멘테이션 출력을 라이다 포인트에 'paint'해 포인트 클라우드와 함께 인코딩하는 PointPainting(early fusion) 패턴이 널리 사용됩니다. 기술적으로는 서로 다른 백본에서 나온 feature를 concat이나 projection으로 결합한 뒤 검출/분류 헤드를 학습합니다.
후기(late) 퓨전은 각 모달리티별로 독립 예측(로그잇/확률)을 만든 다음 의사결정 단계에서 합칩니다. 앙상블, 가중 평균, 메타 분류기를 쓰며 실시간 제한·모달리티 손실(예: 카메라 고장)에 강합니다. 샤드-라텐트(shared-latent)는 모든 모달리티를 공통 임베딩 공간으로 투영해 대조학습(예: CLIP)이나 cross-attention(Flamingo, Perceiver)으로 융합합니다. 이 방식은 검색, 제로샷, 파인튜닝에 유리합니다.

활용

실제 사례와 코드
- PointPainting / MV3D 등 (자율주행 논문): 라이다 점에 2D 세그멘트 확률을 붙여 PointNet 계열에 입력(초기 퓨전). 간단한 PyTorch 예:

img_feat = img_backbone(img)
lidar_feat = lidar_backbone(pcd)
fused = torch.cat([img_proj(img_feat), lidar_proj(lidar_feat)], dim=1)
out = detector_head(fused)

- Late fusion (서비스 레벨 의사결정): 카메라 모델과 텍스트 모델 각각 logits를 만든 뒤 가중 합:

logits = w1*logits_img + w2*logits_text
pred = logits.softmax(dim=-1).argmax(-1)

- Shared-latent (OpenAI CLIP, Google ALIGN, DeepMind Perceiver/Flamingo): 이미지·텍스트를 L2 정규화 후 대조손실 사용:

I = normalize(img_encoder(img))
T = normalize(text_encoder(txt))
logits = I @ T.t() / temp
loss = CE(logits, torch.arange(N))

실무 패턴: 레이턴시·모달리티 신뢰도(health)·데이터 균형을 기준으로 early/late/shared 혼합 전략을 택하고, shared 공간은 배치 크기·negative 샘플링 설계가 성능을 좌우합니다. 출처: OpenAI CLIP, Google ALIGN, Perceiver (DeepMind), PointPainting / MV3D 논문, Waymo/nuScenes 오픈 데이터와 구현들.

Content

Multimodal fusion combines heterogeneous modalities (image, lidar, text) to improve prediction robustness. Early vs. late fusion and shared-latent approaches trade off latency, fault tolerance, and generalization in real systems.

Early fusion merges low-level or mid-level features from multiple modalities into a single network (concatenate, project, then feed to a head). Common in autonomous driving: MV3D/PointPainting fuse 2D segmentation cues with LiDAR points so a single detector learns cross-modal cues. Technically you feed modality-specific backbones, align spatial/temporal frames, project to a common shape, then learn jointly.
Late fusion keeps modality-specific predictors and combines decisions (logits/probabilities) at the end—via weighted average, stacking, or gating. This is robust to missing modalities and simpler to scale when teams manage models independently. Shared-latent approaches (CLIP, ALIGN, Perceiver, Flamingo) map modalities into a joint embedding space via contrastive losses or cross-attention; that space enables retrieval, zero-shot transfer, and compact multimodal representations.

Applications

Real-world code + sources
- Early fusion (autonomous driving — MV3D/PointPainting): attach 2D segmentation scores to LiDAR points and train detector. PyTorch snippet:

img_feat = img_backbone(img)
lidar_feat = lidar_backbone(pcd)
fused = torch.cat([img_proj(img_feat), lidar_proj(lidar_feat)], dim=1)
out = detector_head(fused)

Sources: MV3D / PointPainting papers, Waymo/nuScenes ecosystems.
- Late fusion (service-level ensembles or AV stacks): combine logits from modal-specific models:

logits = w_img*logits_img + w_text*logits_text
pred = logits.softmax(dim=-1).argmax(-1)

Used where uptime and independent deployability matter.
- Shared-latent (CLIP / ALIGN / Perceiver): contrastive training to align image/text embeddings:

I = F.normalize(img_enc(img), dim=1)
T = F.normalize(txt_enc(txt), dim=1)
logits = I @ T.t() / temp
loss = F.cross_entropy(logits, torch.arange(N))

Sources: OpenAI CLIP, Google ALIGN, DeepMind Perceiver/Flamingo. Best practices: monitor modality health, tune fusion point for latency vs. shared learning, and ensure balanced negatives / batch size for contrastive shared-latent training.
